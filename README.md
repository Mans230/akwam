# 🤖 بوت تليجرام أكوام (Akwam Bot)

بوت تليجرام يبحث في موقع **أكوام (akwam)** عن الأفلام والمسلسلات ويعرض لك:

- نتائج البحث (بوستر + سنة + تقييم + نوع) بأزرار تفاعلية.
- **الأفلام**: جودات متعددة — إرسال الفيديو مباشرة داخل تليجرام، أو رابط تحميل مباشر، أو رابط مشاهدة.
- **المسلسلات**: مواسم ← حلقات (20 حلقة في الصفحة) ← نفس خيارات الفيلم + أزرار الحلقة التالية/السابقة.
- زر **"تحميل الموسم كامل"**: يرسل الحلقات واحدة تلو الأخرى تلقائياً.
- الإرسال يتم عبر **سيرفر Bot API محلي** — مما يسمح برفع ملفات حتى **2 جيجابايت** (بدونه الحد الأقصى 50 ميجابايت فقط).
- إمكانية الاشتراك الإجباري بقناة، ولوحة تحكم للأدمن، وحدود تحميل لكل مستخدم، وكاش مؤقت لتسريع الردود.

---

## 📋 المتطلبات

- **للتشغيل على VPS**: [Docker](https://docs.docker.com/get-docker/) + [Docker Compose](https://docs.docker.com/compose/install/) (مثبتان معاً في Docker الحديث).
- **للتشغيل على Railway**: حساب على [railway.app](https://railway.app) فقط.
- توكن البوت + API_ID و API_HASH من تليجرام (الخطوات بالأسفل).

---

## 1️⃣ إنشاء البوت وأخذ التوكن من @BotFather

1. افتح تليجرام وابحث عن **@BotFather** وابدأ محادثة معه.
2. أرسل الأمر:

   ```
   /newbot
   ```

3. اكتب اسماً للبوت (أي اسم يظهر للمستخدمين)، ثم يوزرنايم ينتهي بـ `bot` (مثال: `my_akwam_bot`).
4. سيرسل لك BotFather **التوكن** — نص طويل مثل:

   ```
   123456789:AAEhBOweik6ad9r_QXMENQjcrGbqCr4K-4c
   ```

5. احتفظ بالتوكن، سنضعه في ملف `.env` لاحقاً (خانة `BOT_TOKEN`).

---

## 2️⃣ أخذ API_ID و API_HASH من my.telegram.org

هذان المتغيران **مطلوبان** لتشغيل سيرفر Bot API المحلي الذي يسمح برفع ملفات حتى **2 جيجابايت**:

1. افتح الموقع: [https://my.telegram.org](https://my.telegram.org)
2. سجّل الدخول برقم هاتفك المرتبط بتليجرام (ستصلك رسالة تأكيد داخل تليجرام).
3. اضغط على **API development tools**.
4. املأ النموذج: **App title** و **Short name** (أي اسمين)، ثم اضغط **Create application**.
5. ستظهر لك صفحة فيها:
   - **api_id** → رقم (مثال: `12345678`)
   - **api_hash** → نص (مثال: `abc123def456...`)
6. انسخهما — سنضعهما في ملف `.env` (خانتي `TG_API_ID` و `TG_API_HASH`).

---

## 3️⃣ تعبئة ملف .env

انسخ ملف المثال وأنشئ ملفك الخاص:

```bash
cp .env.example .env
```

ثم افتح ملف `.env` بأي محرر نصوص واملأ القيم. الجدول التالي يشرح كل متغير:

| المتغير | الوصف | مثال |
|---|---|---|
| `BOT_TOKEN` | توكن البوت الذي أخذته من @BotFather (إلزامي) | `123456789:AAEh...` |
| `AKWAM_DOMAIN` | دومين موقع أكوام الحالي — غيّره فقط إذا تغيّر دومين الموقع | `https://akwam.it` |
| `ADMIN_IDS` | آيديات الأدمن مفصولة بفواصل — اعرف آيديك من البوت **@userinfobot** | `123456789,987654321` |
| `FORCE_CHANNEL` | يوزر القناة أو آيديها للاشتراك الإجباري — اتركه فارغاً لتعطيل الميزة. **ملاحظة مهمة**: يجب أن يكون البوت **أدمن في القناة** حتى يستطيع فحص اشتراك الأعضاء | `@mychannel` |
| `BOT_API_SERVER` | عنوان سيرفر Bot API المحلي — اتركه كما هو مع docker-compose، أو اضبطه على العنوان الداخلي في Railway (انظر قسم Railway) | `http://telegram-bot-api:8081` |
| `TG_API_ID` | الـ api_id من my.telegram.org (إلزامي للسيرفر المحلي) | `12345678` |
| `TG_API_HASH` | الـ api_hash من my.telegram.org (إلزامي للسيرفر المحلي) | `abc123def456...` |
| `DEFAULT_MAX_CONCURRENT` | الحد الافتراضي لعدد التحميلات المتزامنة لكل مستخدم — والأدمن يستطيع تخصيص حد مختلف لأي مستخدم من لوحة `/admin` | `1` |
| `CACHE_TTL_HOURS` | مدة بقاء نتائج البحث والصفحات في الكاش (بالساعات) لتسريع الردود | `6` |
| `EPISODES_PER_PAGE` | عدد الحلقات المعروضة في الصفحة الواحدة داخل المسلسل | `20` |
| `DOWNLOAD_DIR` | مجلد حفظ الملفات مؤقتاً أثناء التحميل والرفع (تُحذف تلقائياً بعد الإرسال) | `./downloads` |
| `DB_PATH` | مسار ملف قاعدة بيانات SQLite | `./data/bot.db` |

## 4️⃣ التشغيل على VPS (Docker)

أسهل طريقة — أمر واحد يشغّل البوت مع سيرفر Bot API المحلي:

1. انسخ المشروع إلى السيرفر (مثلاً عبر `git clone`).

2. جهّز ملف `.env` كما في القسم السابق (تأكد أنك ملأت `BOT_TOKEN` و `TG_API_ID` و `TG_API_HASH`).

3. شغّل البوت:

   ```bash
   docker compose up -d --build
   ```

   سيقوم هذا الأمر ببناء صورة البوت وتشغيل خدمتين: `telegram-bot-api` (السيرفر المحلي) و `bot` (البوت نفسه).

4. لمتابعة اللوجز (سجل التشغيل):

   ```bash
   docker compose logs -f bot
   ```

   (اضغط `Ctrl+C` للخروج من عرض اللوجز — البوت سيظل يعمل في الخلفية).

5. لإيقاف البوت:

   ```bash
   docker compose down
   ```

6. لتحديث البوت بعد تعديل الكود:

   ```bash
   docker compose up -d --build
   ```

> 💾 ملفات التحميل المؤقتة تُحفظ في مجلد `downloads/` وقاعدة البيانات في مجلد `data/` — كلاهما مربوط بمجلدات على السيرفر حتى لا تضيع البيانات عند إعادة التشغيل.

## 5️⃣ التشغيل على Railway

> ⚠️ **Railway لا يدعم ملفات docker-compose** — لذلك سننشئ **خدمتين منفصلتين** داخل نفس المشروع ونربطهما عبر الشبكة الداخلية (Private Networking).

### الخدمة الأولى: سيرفر Bot API المحلي

1. من لوحة Railway اضغط **New Project** ← **Deploy a Docker Image**.
2. في خانة اسم الصورة اكتب:

   ```
   aiogram/telegram-bot-api:latest
   ```

3. بعد إنشاء الخدمة، افتح تبويب **Variables** وأضف:

   ```
   TELEGRAM_API_ID=<قيمة api_id>
   TELEGRAM_API_HASH=<قيمة api_hash>
   TELEGRAM_LOCAL_MODE=1
   ```

4. افتح إعدادات الخدمة **Settings** ← **Networking** وفعّل **Private Network** (وتأكد أن المنفذ الداخلي هو `8081`).

### الخدمة الثانية: البوت (من الريبو)

1. داخل نفس المشروع في Railway اضغط **New Service** ← **GitHub Repo** واختر مستودع البوت.
2. سيكتشف Railway ملف `railway.json` تلقائياً ويبني الخدمة من الـ **Dockerfile**.
3. افتح تبويب **Variables** في خدمة البوت وأضف باقي المتغيرات (`BOT_TOKEN` و `ADMIN_IDS` وباقي الجدول في قسم 3️⃣) — عدا متغيرات `TELEGRAM_*` الخاصة بالخدمة الأولى.
4. **الأهم**: اضبط المتغير `BOT_API_SERVER` على **العنوان الداخلي** للخدمة الأولى. تجده في تبويب **Settings ← Networking** الخاص بخدمة `telegram-bot-api`، ويكون عادة بصيغة:

   ```
   BOT_API_SERVER=http://telegram-bot-api.railway.internal:8081
   ```

   (الاسم الدقيق للدومين الداخلي يعتمد على اسم الخدمة عندك — انسخه من صفحة Private Networking في Railway).

5. فعّل **Private Network** أيضاً في خدمة البوت حتى تستطيع الوصول للخدمة الأولى.
6. اضغط **Deploy** وتابع اللوجز من تبويب **Deployments**.

> 📌 **لماذا السيرفر المحلي؟** بدون خدمة `telegram-bot-api` يستطيع البوت رفع ملفات بحجم **50 ميجابايت كحد أقصى** (قيود تليجرام الرسمية). مع السيرفر المحلي يصل الحد إلى **2 جيجابايت**. إذا أردت تشغيل البوت وحده بدون السيرفر المحلي، اترك `BOT_API_SERVER` فارغاً وسيعمل البوت بالحد الافتراضي 50MB.

## ⌨️ أوامر البوت

| الأمر | الوصف |
|---|---|
| `/start` | رسالة ترحيب وتعليمات الاستخدام — بعدها أرسل اسم أي فيلم أو مسلسل للبحث عنه |
| `/admin` | **للأدمن فقط** — لوحة التحكم: 📊 إحصائيات البوت، 📢 إذاعة رسالة لكل المستخدمين، 👤 إدارة مستخدم (حظر / فك حظر / تحديد حد التحميلات المتزامنة له)، 🚫 قائمة المحظورين |

**طريقة الاستخدام للمستخدم العادي**: أرسل اسم الفيلم أو المسلسل كنص عادي ← اختر من النتائج ← اختر الجودة ← "⬇ إرسال" ليصلك الفيديو داخل تليجرام، أو "🔗 رابط" للحصول على رابط تحميل مباشر، أو "👁 مشاهدة" لرابط المشاهدة.

## 🛠 حل المشاكل

### "لا توجد نتائج" لكل عمليات البحث / الموقع لا يستجيب
موقع أكوام يغيّر دومينه من وقت لآخر. حدّث المتغير في `.env`:

```
AKWAM_DOMAIN=https://akwam.it
```

(ضع الدومين الجديد الصحيح)، ثم أعد تشغيل البوت: `docker compose up -d --build`.

### خطأ "Unauthorized" أو البوت لا يقلع
التوكن غير صحيح. تأكد أنك نسخت `BOT_TOKEN` كاملاً من @BotFather بدون مسافات زائدة في بدايته أو نهايته.

### البوت لا يتحقق من اشتراك الأعضاء في القناة
يجب أن يكون البوت **أدمن (مشرف)** في القناة المحددة في `FORCE_CHANNEL` حتى يستطيع فحص العضوية. أضف البوت للقناة كمشرف ثم جرّب زر "✅ تحققت" مرة أخرى.

### خدمة telegram-bot-api تتوقف فور التشغيل
تأكد من تعبئة `TG_API_ID` و `TG_API_HASH` بقيم صحيحة من my.telegram.org — الخدمة لا تعمل بدونهما.

### امتلاء مساحة التخزين
الملفات تُحذف تلقائياً بعد إرسالها، لكن عند وجود تحميلات كثيرة متزامنة قد تمتلئ المساحة. تحقق من مجلد التحميلات:

```bash
du -sh downloads/
```

واحذف أي ملفات متبقية قديمة (من تحميلات ملغاة أو فاشلة) بأمان:

```bash
rm -f downloads/*.mp4
```

### البوت بطيء في إرسال الفيديوهات الكبيرة
هذا طبيعي — البوت يحمل الملف أولاً ثم يرفعه لتليجرام. السرعة تعتمد على سرعة سيرفرك. الملفات فوق 50MB **لن تُرسل إلا مع السيرفر المحلي** (تأكد أن `BOT_API_SERVER` مضبوط بشكل صحيح).
